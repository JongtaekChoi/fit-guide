# 측정 기준점과 비율 계산 규칙

## 분석 전제

FitGuide는 사진에서 실제 신체 치수나 둘레를 정밀 측정하지 않는다. 정면 전신사진의 기준점으로 **상대 길이와 폭의 비율**을 계산한다. 키는 필요할 때 대략적인 의류 길이 범위를 제시하는 보조값으로만 사용한다.

## 촬영 조건

- 정면을 보고 선다.
- 전신과 발바닥이 한 화면에 들어오게 한다.
- 카메라는 허리 높이에 두고 수직을 유지한다.
- 팔은 몸통과 분리되도록 자연스럽게 약간 벌린다.
- 다리는 발목 간격이 보일 만큼 약간 벌린다.
- 몸의 윤곽이 보이는 단색 상·하의를 권장한다.
- 거울 셀카, 과한 광각, 한쪽 다리에 체중을 싣는 자세는 피한다.

## 기준점

| 기준점 | 자동 감지 | 사용자 보정 | 활용 |
| --- | --- | --- | --- |
| 머리 꼭대기 | 어려움 | 필수 | 전체 키, 머리 길이 |
| 턱 아래 | 어려움 | 필수 | 머리 길이, 목 시작점 |
| 왼쪽·오른쪽 어깨 | 가능 | 선택 | 어깨 폭, 팔 길이 시작점 |
| 왼쪽·오른쪽 손목 | 가능 | 선택 | 팔 길이 |
| 왼쪽·오른쪽 골반 | 가능 | 선택 | 상체·하체 경계, 골반 폭 |
| 허리선 중심 | 추정 | 권장 | 허리선 위치 |
| 왼쪽·오른쪽 발목 | 가능 | 선택 | 다리 길이 |
| 바닥선 | 추정 | 권장 | 전체 키 기준 |

## 계산 정의

사진 좌표계에서는 같은 사진 안의 길이 비율을 사용한다. 각 세로 길이는 화면의 y축 거리, 폭은 x축 거리로 계산한다.

| 지표 | 계산 | 해석 |
| --- | --- | --- |
| 머리 비율 | 머리 꼭대기~턱 / 머리 꼭대기~바닥 | 전체 대비 머리 크기 |
| 상체 비율 | 어깨 중심~골반 중심 / 머리 꼭대기~바닥 | 몸통 길이의 상대값 |
| 하체 비율 | 골반 중심~바닥 / 머리 꼭대기~바닥 | 다리 길이의 상대값 |
| 팔 길이 비율 | 어깨~손목 / 머리 꼭대기~바닥 | 팔의 상대 길이 |
| 어깨 폭 비율 | 좌우 어깨 거리 / 머리 너비 | 머리 대비 어깨 폭 |
| 골반 대비 어깨 | 어깨 폭 / 골반 폭 | 상체 실루엣 방향 |
| 허리선 위치 | 머리 꼭대기~허리선 / 머리 꼭대기~바닥 | 시각적 색 경계·밑위 조언 |

## 신뢰도 처리

다음 중 하나라도 충족하지 않으면 ‘다시 촬영 권장’을 먼저 보여준다.

- 발바닥 또는 머리 꼭대기가 화면 밖에 있음
- 어깨·골반·발목 좌우 중 한쪽을 찾지 못함
- 화면의 세로축과 몸 중심축이 과도하게 기울어짐
- 손 또는 발이 가려짐
- 인물의 화면 점유율이 너무 작음

보정 후에는 각 지표에 `확인됨`, `추정됨`, `촬영 조건 부족` 상태를 붙인다.

## 첫 출시에서 제외하는 측정

정면사진 한 장만으로 신뢰하기 어려운 아래 항목은 계산하지 않는다.

- 목둘레, 가슴둘레, 허리둘레, 허벅지둘레
- 실제 인심과 실제 팔 길이(cm)
- 체지방률
- 목 두께
- 얼굴형·헤어스타일 적합도
- 측면 자세 및 굽은 어깨 평가

이 항목들은 측면 사진 또는 수동 측정이 추가되는 다음 단계에서 검토한다.
