# FitGuide MVP 명세

## 문제

온라인에서 옷을 살 때 사용자는 `L`, `XL`, 오버핏 같은 불완전한 표기만으로 자신의 체형에 맞는 선택을 해야 한다. 키와 체중만으로는 상·하체 비율, 어깨 폭, 팔·다리 길이, 허리선 위치 같은 차이를 설명하기 어렵고, 줄자로 여러 부위를 재는 과정도 번거롭다.

## 제품 가설

전신사진에서 자동으로 찾은 신체 기준점을 사용자가 가볍게 보정하게 하면, 줄자 측정보다 낮은 부담으로 납득 가능한 비율 프로필을 만들 수 있다. 이 프로필에 근거와 함께 코디 원칙을 제공하면, 사용자는 자신의 옷 길이와 실루엣을 더 일관되게 고를 수 있다.

## 대상 사용자

첫 번째 사용자는 온라인에서 옷을 고를 때 기장과 전체 비율 때문에 실패를 줄이고 싶은 30~40대 남성이다. 첫 출시에서 성별이나 체형을 제한하지는 않지만, 추천 규칙과 예시는 남성 캐주얼 착장을 우선으로 한다.

## 핵심 사용자 흐름

1. 사용자가 키와 선호 핏을 입력한다.
2. 촬영 가이드에 따라 정면 전신사진을 촬영하거나 업로드한다.
3. 포즈 인식이 자동으로 주요 기준점을 배치한다.
4. 사용자가 잘못 잡힌 기준점만 드래그해 보정한다.
5. FitGuide가 상대 비율과 체형 특징을 계산한다.
6. 상의·하의·전체 비율에 대한 코디 원칙 3~5개를 보여준다.
7. 사진은 폐기하고 분석 결과만 기기에 저장한다.

## MVP 화면

| 화면 | 목적 | 필수 요소 |
| --- | --- | --- |
| 시작 | 서비스 이해와 개인정보 기대치 설정 | 한 문장 소개, 사진 기기 내 처리 안내 |
| 촬영 가이드 | 분석 가능한 사진 확보 | 자세·복장·카메라 높이 안내 |
| 사진 보정 | 자동 분석 오차를 사용자가 바로잡음 | 사진, 기준점, 확대·되돌리기 |
| 비율 결과 | 내 몸의 기록을 확인 | 비율 카드, 기준점 설명, 측정 신뢰도 |
| 코디 가이드 | 분석을 행동으로 연결 | 상의·하의·전체 조언, 이유 |
| 기록 | 다음 분석과 비교 | 날짜별 프로필, 수동 삭제 |

## 핵심 결과

- 상체 : 하체 비율
- 어깨너비 : 머리너비 비율
- 팔 길이 : 전체 키 비율
- 다리 길이 : 전체 키 비율
- 허리선의 상대적 위치
- 어깨와 골반 너비의 상대적 차이

각 결과는 ‘좋음/나쁨’ 점수가 아니라 **상대적 특징**으로 표현한다. 예: “상체 비율이 상대적으로 긴 편입니다.”

## 추천 출력 원칙

각 추천은 `관찰 → 영향 → 행동`의 구조를 지킨다.

> 상체 비율이 상대적으로 긴 편입니다. 상의 총장이 골반을 크게 덮으면 상체의 비중이 더 커 보일 수 있습니다. 골반 중간을 넘지 않는 길이와 중간 이상 밑위의 바지를 우선 비교해 보세요.

### 첫 출시의 추천 영역

- 상의: 총장, 어깨선, 품, 소매 길이
- 하의: 밑위, 통, 기장, 허리선
- 전체: 상하의 색 경계, 상의 넣어 입기, 아우터 길이

## 비기능 요구사항

- 원본 사진을 서버에 업로드하지 않는다.
- 분석과 기준점 보정은 브라우저에서 수행한다.
- 로그인 없이 사용할 수 있어야 한다.
- 결과 저장은 기본적으로 로컬 저장소를 사용한다.
- ‘의학적 측정’, ‘정확한 cm 측정’, ‘체형 교정’ 같은 표현을 사용하지 않는다.

## 성공 기준

- 자동 인식 뒤 소수의 기준점 보정만으로 결과를 만들 수 있다.
- 본인의 보유 옷과 착용 경험을 대입했을 때 결과와 조언을 납득할 수 있다.
- 결과를 다시 볼 이유가 있는 개인 체형 프로필이 생성된다.
