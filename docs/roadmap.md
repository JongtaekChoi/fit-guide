# 개발 로드맵

## Phase 0 — 기준 확정

목표: 무엇을 측정하고 무엇을 측정하지 않는지 명확히 한다.

- [x] 제품 가설과 MVP 범위 정의
- [x] 촬영 조건·기준점·비율 계산 규칙 정의
- [ ] 첫 결과 문장 규칙 10개 작성
- [ ] 본인 사진과 보유 옷으로 결과를 검토할 체크리스트 작성

완료 기준: 기획 문서만 보고도 동일한 비율 계산과 결과 문장을 구현할 수 있다.

## Phase 1 — 사진 보정 POC

목표: 사진 위 기준점 자동 감지와 수동 보정이 실제로 쓸 만한지 확인한다.

- [ ] 모바일 웹 프로젝트 초기화
- [ ] 정면 사진 업로드 및 캔버스 표시
- [ ] 브라우저 내 포즈 인식으로 어깨·손목·골반·발목 감지
- [ ] 머리 꼭대기·턱·허리선 수동 지정
- [ ] 기준점 드래그 보정
- [ ] 비율 카드 출력
- [ ] 사진 메모리 해제·로컬 저장 제외 처리

완료 기준: 본인 사진으로 상·하체, 어깨, 팔, 다리 비율을 한 번에 생성하고 납득할 수 있다.

## Phase 2 — 개인 체형 카드

목표: 계산 결과를 다시 볼 가치가 있는 개인 기록으로 만든다.

- [ ] 체형 특징 문장 생성
- [ ] 상의·하의·전체 코디 원칙 3~5개 출력
- [ ] 결과 로컬 저장
- [ ] 재분석 및 기록 삭제
- [ ] 모바일 UI 다듬기

완료 기준: 사진을 다시 올리지 않아도 내 체형 특징과 코디 원칙을 확인할 수 있다.

## Phase 3 — 유용성 검증

목표: 실제 옷 선택에 도움이 되는지 확인한다.

- [ ] 보유 상의·하의 각각 5벌에 결과 적용
- [ ] ‘잘 맞는 옷’과 ‘아쉬운 옷’의 실제 경험을 기록
- [ ] 조언의 납득도와 오류를 기록
- [ ] 규칙 조정

완료 기준: 적어도 본인에게는 추천의 이유가 착용 경험과 일관된다.

## Phase 4 후보 — 사진 코칭 검증

목표: 체형 비율 가이드를 다음 촬영 행동으로 연결할 수 있는지 확인한다.

- [ ] 전신 코디 사진 1장 업로드 흐름 설계
- [ ] ‘잘 된 점 1개 + 다음 사진의 행동 3개’ 출력 규칙 작성
- [ ] 코디 비율·포즈·카메라·배경의 피드백 템플릿 작성
- [ ] 사진 처리 경로와 외부 AI 사용 고지 원칙 결정
- [ ] 본인 사진으로 재촬영 전후의 납득도 기록

완료 기준: 피드백을 본 뒤 실제로 다시 촬영할 이유가 생기고, 적어도 하나의 제안을 적용할 수 있다.

상세 기획: [사진 코칭 기능 기획](product/photo-coaching.md)
