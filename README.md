# FitGuide

> 사진 기반 신체 비율 분석으로, 나에게 어울리는 옷의 실루엣과 코디 원칙을 알려주는 개인 스타일 가이드

FitGuide는 정면 전신사진과 키를 바탕으로 머리·어깨·상체·팔·다리의 **상대 비율**을 분석합니다. 사진에서 정확한 신체 치수를 측정한다고 주장하지 않으며, 자동으로 잡힌 기준점을 사용자가 직접 보정할 수 있게 설계합니다.

## 첫 번째 목표

정면 사진 한 장에서 주요 기준점을 자동으로 표시하고, 사용자가 조금 보정하면 납득 가능한 체형 비율 카드를 만든다.

## MVP 범위

- 정면 전신사진 촬영 또는 업로드와 키 입력
- 주요 기준점 자동 감지 및 수동 보정
- 상·하체, 머리·어깨, 팔·다리, 허리선 비율 계산
- 비율 기반 체형 특징과 상의·하의·전체 코디 원칙 제공
- 사진은 기기 안에서 처리하고, 결과 데이터만 로컬에 저장

## 제외 범위

- 사진만으로 둘레(cm)를 정밀 측정하는 기능
- 쇼핑몰 상품 자동 수집·추천
- 계정, 서버 저장, 커뮤니티
- AI 생성 착장 이미지
- 헤어스타일 추천

## 원칙

- 신체를 등급화하거나 부정적으로 평가하지 않는다.
- 추천에는 관찰된 비율과 이유를 함께 제시한다.
- 민감한 사진과 신체 정보는 가능한 한 기기 밖으로 나가지 않게 한다.
